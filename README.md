## 🌟 Tentang Project

Landing page single-file HTML + CSS + JS yang dirancang dengan estetika **dark modern** dan nuansa merah premium. Cocok untuk jasa pembuatan website, digital agency, freelancer, atau studio kreatif.

**Live Demo**: [https://aclester.my.id](https://aclester.my.id) *(ganti dengan link kamu)*

## ✨ Fitur Utama

- **Fully Responsive** — Tampil sempurna di semua perangkat
- **Dark Modern Design** dengan accent merah mencolok
- **Smooth Scroll & Reveal Animation**
- **Mobile-friendly Navigation** (Hamburger menu)
- **SEO Optimized** (meta tags lengkap)
- **Performa Tinggi** — Single file, tidak ada framework berat
- **WhatsApp CTA** yang langsung terhubung
- **Portfolio & Services Section**
- **Process / Cara Kerja**

## 🛠️ Teknologi yang Digunakan

- **HTML5**
- **CSS3** (Custom vanilla CSS + CSS Variables)
- **Vanilla JavaScript**
- Google Fonts (`Plus Jakarta Sans` & `Unbounded`)
- Fully Responsive Grid & Flexbox
